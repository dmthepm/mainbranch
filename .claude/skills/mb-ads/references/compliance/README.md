# Compliance Reference

Planning-phase resources: decide what TYPE of ads to create before writing them. The review-phase lenses in `../lenses/` check written ads (see [review-workflow.md](../review-workflow.md)).

| File | Use |
|------|-----|
| `ftc-scrutiny-categories.md` | Before any campaign: which industries get extra FTC attention |
| `angle-playbook.md` | When planning angles: every persuasion angle with its rules |
| `testimonial-decision-rubric.md` | Before using outcome testimonials |

## Pre-Campaign Checklist

1. **FTC scrutiny tier** (`ftc-scrutiny-categories.md`): Tier 1 defaults to non-outcome angles; Tier 2 outcome testimonials need proper disclosure; Tier 3 standard compliance.
2. **Angles** (`angle-playbook.md`): which fit this offer, each angle's compliance requirements, which to avoid.
3. **Outcome testimonials** (`testimonial-decision-rubric.md`): score below 5 uses alternative angles; 5 or more checks typicality data.
4. **Typicality data** in the business repo at `core/proof/typicality.md`: with data, use it for disclosures; marked "DATA NEEDED", block outcome testimonials; missing, create it and flag as a research task.

Low compliance burden: mechanism, social proof (scale), risk reversal, community, process testimonials, curiosity. High burden: outcome testimonials, urgency/scarcity, pain agitation (Meta). When in doubt, use low-burden angles.
