# Picking the day's move

Score each candidate 1 to 3 on four questions, then take the highest total. Break
ties toward the move that is easier to undo.

| Question | 3 | 1 |
|---|---|---|
| Effect on the number | touches the step right before it | indirect, several steps away |
| Time to a readable signal | days | months |
| Cost (money and owner time) | none | needs spend or an owner sitting |
| Undo | one revert | hard to take back |

## Where moves come from

- **Search** (`/mb-seo`): pages losing clicks, queries with impressions and no
  clicks, missing titles or descriptions, thin pages for a real query, AI-answer
  visibility gaps. OpenSEO and Search Console give the data when connected.
- **Pages and conversion** (`/mb-site`, CRO agent): the step where visitors drop,
  unclear offer lines, slow pages, broken forms, missing proof near the ask.
- **Paid** (`/mb-ads`): pause losers, test a new hook, tighten audiences. Budget
  changes always ask.
- **Content** (`/mb-organic`): a post answering a real question customers asked.
  Publishing always asks; drafting does not.
- **Research** (`/mb-think`): when the number is stuck and no move scores above
  6, spend the day finding out why.
- **Read paths**: when the number cannot be read, fixing that is the move.

## Do not

- start a move whose signal cannot be read before the next review;
- run two moves on the same page or audience in the same week;
- count a draft as a move. A move changes something real, or prepares an
  always-ask action and asks.
