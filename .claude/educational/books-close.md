# Close books from source evidence

Use the [statement-anchored books workflow](docs/books-workflow.md) to collect
evidence, review rules, check each source lane, and close with balance
assertions. The [synthetic books repo template](mb/mb/_data/books/repo-template/)
shows the entrypoint, rules, manifest, blocker list, and doctor shape.

Real books belong in a private books vault or restricted repo. `mb books`
checks setup and safety; hledger and the private books repo own ledger entries.
